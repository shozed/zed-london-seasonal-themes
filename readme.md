# London Seasonal Themes
Currently I've only added Columbia Road and Soho Night, because I use these myself.
I took the colours from [Scott Matthews' pull request](https://github.com/mbadolato/iTerm2-Color-Schemes/pull/699).
Therefore, credit where credit is due.

## Credits
The London Columbia Road, London Soho Night, London Bonfire Night, and London Embankment Dusk themes were created by [Scott Matthews](https://github.com/scottmatthews7) as a four-theme seasonal set, each anchored to a specific place and time in London: Columbia Road flower market in spring, a Soho side street in summer, Hampstead Heath on Bonfire Night in autumn, and the Embankment at dusk in winter.

## Installation

### Method 1
1. [Download the repository as a ZIP](https://github.com/shozed/zed-london-seasonal-themes/archive/refs/heads/main.zip)
2. Unzip the ZIP
3. Open Zed and open the extensions store (Command + Shift + X on macOS)
4. Click "Install Dev Extensions" in the top right
5. A window will open where you will select the unziped repository
6. Select the theme you'd like to use and have fun!

### Method 2
1. [Download the repository as a ZIP](https://github.com/shozed/zed-london-seasonal-themes/archive/refs/heads/main.zip)
2. Unzip the ZIP
3. Move the contents of ./themes into ~/.config/zed/themes 
4. Select the theme you'd like to use and have fun!
